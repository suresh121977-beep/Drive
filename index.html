Setup help

Google Cloud Console: new project, enable Google Drive API, OAuth consent screen (add yourself as test user), Credentials, OAuth client ID (Web). Add this page's origin (e.g. https://name.github.io) under Authorized JavaScript origins. Paste the Client ID above.

Matches files by content hash (MD5). The oldest copy in each group is kept; others are pre-selected. Trash is recoverable for 30 days.






Encrypted or split files are uploaded as numbered parts plus a .manifest.json that lists every part name, used later to merge. Encryption is AES-256-GCM in your browser; the password is never stored or sent.
